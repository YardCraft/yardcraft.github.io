Обновление клиентских сборок

Для YardCraft доступны две клиентские сборки 2.0 на Minecraft 26.2. Основная сборка YardCraft предназначена для обычных компьютеров. YardCraft Potato — облегчённый вариант для слабых компьютеров.

Загрузка и установка

Выберите один ZIP и импортируйте его через «Добавить экземпляр» → «Импорт» в PineconeMC. Оставьте архив в формате ZIP. На странице сборок есть общая инструкция по установке.

Предыдущие выпуски 1.1 обеих сборок доступны на той же странице.
